# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

菜单「暂停闸」按灯种控制领取：暂停后该灯种的待处理任务不被领取，其它灯种照常；恢复后继续领取。每次暂停/恢复都会记入闸门流水。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3195 |
| 接口 | http://localhost:8195 |
| PostgreSQL | localhost:54395 |

| 用户 | 密码 | 权限 |
|------|------|------|
| calibrator | calib123456 | 可提交校准、可暂停/恢复灯种闸门 |
| inspector | insp123456 | 只看（含闸门状态与流水） |

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 菜单「暂停闸」展示各灯种状态与待处理数；calibrator 暂停某灯种后，该灯种待处理任务不被领取，其它灯种照常；恢复后继续领取；暂停/恢复均记入闸门流水。
5. inspector 打开「暂停闸」为只读，无暂停/恢复按钮，直接调接口返回 403。
6. 氦灯有待处理时暂停氦灯，再提交汞灯新单，汞灯先被领取（氦灯保持待处理）；恢复氦灯后，氦灯才被领取。
