# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

菜单「暂停闸」展示各灯种闸门状态与待处理数，校准员可暂停/恢复某灯种的领取，闸门动作记入流水；巡检员只读。灯种被暂停后领取进程跳过其待处理任务，其它灯种照常，恢复后继续领取。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 菜单「暂停闸」展示各灯状态与流水；calibrator 可暂停/恢复，动作记流水；inspector 只读，无操作按钮且调用接口被拒。
5. 氦灯有待处理任务时暂停氦灯，再提交汞灯新单，汞灯先出结论而氦灯仍待处理；恢复氦灯后氦灯才被领取出结论。
